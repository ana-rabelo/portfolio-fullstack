# Portfólio de Ana Paula Rabelo

Portfólio estático de uma desenvolvedora full-stack, publicado no GitHub Pages.

## Conteúdo

Os projetos apresentados apontam para repositórios públicos do perfil [ana-rabelo](https://github.com/ana-rabelo):

- [Imobiliária API](https://github.com/ana-rabelo/imobiliaria-api)
- [Alfood](https://github.com/ana-rabelo/alfood)
- [Alura Space](https://github.com/ana-rabelo/space-django)
- [Petclinic JHipster](https://github.com/ana-rabelo/petclinic-jhipster)

O layout foi inspirado na [referência visual de Isabella Popescu / QClay no Dribbble](https://dribbble.com/shots/25456502-Website-Designer-Portfolio-Website), com conteúdo, composição e elementos gráficos adaptados para este portfólio.

## Desenvolvimento

O site usa somente HTML e CSS. Abra `index.html` no navegador ou execute um servidor estático local. Não há etapa de build.

## Publicação

Em **Settings → Pages**, selecione **Deploy from a branch** com `main` e a pasta `/ (root)`. O endereço publicado é [ana-rabelo.github.io/portfolio-fullstack](https://ana-rabelo.github.io/portfolio-fullstack/).
